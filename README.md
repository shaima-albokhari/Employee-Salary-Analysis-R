# Employee Salary Analysis in R

An exploratory data analysis of an employee salary dataset using **R** and **dplyr**. The project covers data frames, data cleaning, descriptive statistics, grouping, filtering, and visualization.

## What the analysis covers

1. Import the dataset and create a data frame
2. Explore it (`head`, `dim`, `names`, `str`)
3. Clean it: missing values, numeric conversion, duplicates, valid salary records
4. Descriptive statistics for salary (mean, median, min, max, SD, Q1, Q3)
5. Overtime statistics (`Overtime = Payroll_Salary - HR_Salary`)
6. Group by department and by job title
7. Highest salaries, salary filter (> 80,000), overtime filter (> 500)
8. Visualizations: histogram, bar chart, boxplot, scatter plot, and an extra chart by occupational level
9. Correlation between base salary and overtime pay

## Getting started

**Requirements:** R (>= 4.0) and the `dplyr` package.

```bash
git clone https://github.com/shaima-albokhari/employee-salary-analysis-r.git
cd employee-salary-analysis-r

# 1. Add the dataset to data/employee_salary_data.csv
# 2. Install the dependencies
Rscript scripts/install_packages.R
# 3. Run the analysis (from the project root)
Rscript scripts/employee_salary_analysis.R
```

To use the notebook instead, open `notebooks/employee_salary_analysis.ipynb` in Jupyter with the R kernel (IRkernel) or in Google Colab (R runtime). In the notebook the file path is `/content/employee_salary_data.csv` (the Colab upload location), so change it if you run it elsewhere.

## Key findings

- Salaries range from **48,000 to 98,000**, with a mean of **69,400**.
- Average salary rises with occupational level, from **52,250 (Junior)** to **92,666.67 (Senior)**.
- Base salary and overtime pay have a positive correlation of **0.675**.

## Notes and limitations

- The dataset is small (30 employees), so results are descriptive and not statistically conclusive.
- `Overtime` is derived as `Payroll_Salary - HR_Salary`, so it can be negative where payroll paid less than the HR salary.
- `Manager_ID` is missing for employees with no manager; these rows are kept because their salary data is valid.
